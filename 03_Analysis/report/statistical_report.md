# 統計解析レポート: 地形傾斜度と骨折リスクの関連

## 1. 要約 (Executive Summary)
本解析では、NDBオープンデータ（骨折手術）、2020年国勢調査、および国土数値情報（平均傾斜度）を統合し、都道府県レベルでの関連を検証した。
主な結果は以下の通りである：
- **大腿骨近位部骨折発生率**は、**居住地傾斜度（加重平均傾斜）**と有意な正の相関を示した（r = 0.47, p < 0.01）。
- 重回帰分析において、**高齢化率、歩行速度、人口密度を調整した後も、傾斜度は大腿骨骨折発生率と有意に関連していた**（係数 3.49, p = 0.043）。
- 一方、上腕骨や前腕骨の骨折発症率とは有意な関連が見られなかった。
- これにより、傾斜地居住は大腿骨骨折の独立したリスク因子である可能性が示唆された。

## 4. 回帰分析 (Regression Analysis)
(詳細は `regression_results.txt` 参照)

### ターゲット: 大腿骨骨折発生率 (Femur Fracture Rate)

#### Model 1: 単回帰分析
- **説明変数**: 居住地傾斜度
- **結果**:
    - 係数: 5.65 (95%CI: 2.50 - 8.79)
    - p値: **0.0007**
    - 決定係数 (R2): 0.225
- **解釈**: 傾斜度が1度上がると、人口10万人あたりの大腿骨骨折手術が約5.6件増加する。

#### Model 2: 重回帰分析 (多変量調整)
- **説明変数**: 居住地傾斜度 + 高齢化率 + 歩行速度(速い) + 人口密度
- **結果**:
    - **居住地傾斜度**: 係数 3.49 (p = **0.043**)
    - **高齢化率**: 係数 5.53 (p = 0.011)
    - 決定係数 (R2): 0.385
- **解釈**: 高齢化率などの交絡因子を考慮しても、傾斜度は有意に大腿骨骨折リスクを高める要因である。

### 他の部位
- **総骨折**: 重回帰にて傾斜度は傾向を示すが有意水準には達しなかった (p=0.099)。高齢化率が最も強い予測因子であった。
- **上腕骨・前腕骨**: 傾斜度との有意な関連は認められなかった。

## 5. 結論と考察
本研究の結果、**居住地の傾斜は大腿骨近位部骨折の地域差を説明する重要な環境因子の一つである**ことが示唆された。
特に、高齢化の影響を調整してもなお統計的に有意な関連が残った点は重要である。
上腕骨や前腕骨（転倒時に手をついて受傷することが多い）との関連が見られなかったことから、傾斜地特有の歩行負荷や転倒メカニズムが大腿骨骨折リスクに特異的に寄与している可能性が考えられる。
